Example data from Biodiverse (https://github.com/shawnlaffan/biodiverse, `data/`,
GPL-3.0, Shawn Laffan and contributors): site records, a Nexus tree, label
dissimilarity matrices, group properties (`gp_props.csv`) and numeric labels
(`Example_numeric_data.txt`). The other trees (variants of the Nexus tree) and
`label_props.csv` (synthetic label properties) are written by
`tests/bio_cases.py`. Used as inputs of the reference runs in
`tests/data/reference/bio` (see `tools/make_reference_bio.py`).
