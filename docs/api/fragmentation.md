### Landscape mosaic classes

`ls.LM19_CLASSES` names the 19 classes: 1–3 one type above 60%
(agriculture, developed, forest), 4–12 two or three types in a given order of
dominance, 13–16 mosaics without a dominant type, 17–19 pure (100%)
forest, agriculture or developed, and 0 missing.
